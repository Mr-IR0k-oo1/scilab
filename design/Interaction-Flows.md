# Interaction Flows

## Create Project

```
Welcome Screen
    ↓
Click "New Project"
    ↓
Enter Name
    ↓
Select Template (or Blank)
    ↓
Configure Variables (if template)
    ↓
Create Project
    ↓
Open in Workspace
```

## Build GUI

```
Open GUI Builder
    ↓
Drag Widget from Palette
    ↓
Drop on Canvas
    ↓
Select Widget
    ↓
Edit Properties in Inspector
    ↓
Add More Widgets
    ↓
Connect to Scilab Variables (optional)
    ↓
Preview GUI
    ↓
Generate Code
    ↓
Save GUI Definition
```

## Import and Visualize Data

```
Click "Import Data"
    ↓
Select CSV File
    ↓
Preview Data Table
    ↓
Confirm Import
    ↓
Click "New Chart"
    ↓
Select Chart Type
    ↓
Map Columns to Axes
    ↓
Configure Options (title, labels)
    ↓
Render Chart
    ↓
Interact (zoom, hover, select)
    ↓
Export (PNG, SVG, CSV)
```

## Generate Report

```
Click "New Report"
    ↓
Add Heading Block
    ↓
Write Introduction
    ↓
Add Chart Block
    ↓
Select Embedded Chart
    ↓
Add Table Block
    ↓
Insert Data Table
    ↓
Add Code Block
    ↓
Insert Scilab Code
    ↓
Preview Report
    ↓
Export PDF
```

## Run Scilab Code

```
Open Code Editor
    ↓
Write Scilab Code
    ↓
Press F5 (Run)
    ↓
Code Sent to Scilab
    ↓
Output Appears in Console
    ↓
Errors Appear in Problems Panel
    ↓
Fix Errors
    ↓
Run Again
```
