## Naming Convention

```
ss-icon-{name}
```

Examples: `ss-icon-play`, `ss-icon-save`, `ss-icon-chart-line`

## Sizes

| Size | Dimensions | Use |
|------|-----------|-----|
| xs | 12×12 | Inline, badges |
| sm | 16×16 | Menu items, tree |
| md | 20×20 | Toolbars, tabs |
| lg | 24×24 | Sidebar nav |
| xl | 32×32 | Welcome screen |

## Rules

- Always paired with text in menus/toolbars.
- Exception: compact toolbar buttons.
- Stroke width: 1.5px.
- Style: outline (not filled).
- Color: inherits from parent.
