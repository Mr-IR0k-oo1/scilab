## [0.1.0] - 2026-XX-XX

### Added
- **Initial platform architecture** — Modular runtime with event-driven inter-module communication.
- **Plugin system skeleton** — Manifest format, loader, dependency resolver, and manager UI.
- **Core module definitions** — Specifications for all 18 modules including interfaces and dependencies.
- **Project workspace** — Project model, directory structure, auto-save, and session recovery.
- **Basic GUI builder** — Drag-and-drop canvas with 10 foundational widgets and property editor.
- **Basic visualization** — SVG/Canvas rendering pipeline with 5 core chart types (Line, Bar, Scatter, Histogram, Pie).
- **Documentation foundation** — API reference, file formats, deployment guide, UI/UX guidelines, and developer guide.
- **Community infrastructure** — Code of Conduct, Contributing guidelines, Security policy, and Changelog.
- **CI/CD pipeline** — Automated builds for Linux, macOS, and Windows with test integration.
- **License** — GPL v3 open-source license.
