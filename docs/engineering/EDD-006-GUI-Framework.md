# EDD-006: GUI Framework

## Purpose

The GUI Framework manages the drag-and-drop canvas, component palette, property inspector, and code generation for the Visual GUI Builder.

## Architecture

```
┌─────────────────────────────────────────┐
│          GUI Framework                   │
├─────────────────────────────────────────┤
│  ┌───────────┐  ┌──────────────────┐   │
│  │ Canvas    │  │ Component        │   │
│  │ Manager   │  │ Palette          │   │
│  └───────────┘  └──────────────────┘   │
│  ┌───────────┐  ┌──────────────────┐   │
│  │ Property  │  │ Code             │   │
│  │ Inspector │  │ Generator        │   │
│  └───────────┘  └──────────────────┘   │
│  ┌──────────────────────────────────┐  │
│  │ Selection & Manipulation         │  │
│  └──────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

## Components

### Canvas Manager

Manages the design canvas where widgets are placed.

```typescript
interface CanvasManager {
  addWidget(type: string, position: Point): WidgetInstance;
  removeWidget(instanceId: string): void;
  moveWidget(instanceId: string, position: Point): void;
  resizeWidget(instanceId: string, size: Size): void;
  getWidgets(): WidgetInstance[];
  clear(): void;
}
```

**Canvas Features:**
- Grid snap (toggleable, default 10px).
- Alignment guides.
- Multi-select (Shift+Click, rubber band).
- Undo/redo.

### Component Palette

Shows available widgets grouped by category.

```typescript
interface ComponentPalette {
  getCategories(): string[];
  getComponents(category: string): WidgetDefinition[];
  search(query: string): WidgetDefinition[];
}
```

### Property Inspector

Edits the selected widget's properties.

```typescript
interface PropertyInspector {
  getProperties(instanceId: string): PropertyGroup[];
  setValue(instanceId: string, property: string, value: any): void;
  setBinding(instanceId: string, property: string, expression: string): void;
}
```

**Property Groups:**
- Data (value, expression)
- Layout (x, y, width, height)
- Appearance (color, font, visibility)
- Events (onClick, onChange)

### Code Generator

Generates Scilab code from the GUI layout.

```typescript
interface CodeGenerator {
  generate(layout: WidgetInstance[]): string;
  generateEvents(widgets: WidgetInstance[]): string;
  generateBindings(widgets: WidgetInstance[]): string;
}
```

**Generated Code:**
```scilab
// Auto-generated by Scilab Studio
function create_gui()
    // Create buttons
    uicontrol("style", "pushbutton", ...
              "string", "Run", ...
              "position", [100, 200, 120, 40], ...
              "callback", "run_clicked()");

    // Create labels
    uicontrol("style", "text", ...
              "string", "Result:", ...
              "position", [100, 160, 120, 20]);
endfunction
```

### Selection & Manipulation

```typescript
interface SelectionManager {
  select(instanceId: string, additive?: boolean): void;
  deselect(instanceId: string): void;
  deselectAll(): void;
  getSelected(): WidgetInstance[];
  moveSelected(delta: Point): void;
  deleteSelected(): void;
  copySelected(): void;
  paste(): void;
}
```

**Keyboard Shortcuts:**
| Key | Action |
|-----|--------|
| Arrow keys | Nudge 1px |
| Shift+Arrow | Nudge 10px |
| Delete | Delete selected |
| Ctrl+A | Select all |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |

## GUI Definition File

GUIs are stored as `.gui.json`:

```json
{
  "version": "1.0",
  "widgets": [
    {
      "id": "btn_run",
      "type": "button",
      "properties": { "label": "Run", "width": 120, "height": 40 },
      "position": { "x": 100, "y": 200 },
      "events": { "onClick": "run_clicked()" }
    },
    {
      "id": "lbl_result",
      "type": "label",
      "properties": { "text": "Result:" },
      "position": { "x": 100, "y": 160 }
    }
  ]
}
```

## Error Handling

- Invalid widget type: show error on canvas.
- Code generation failure: log, show partial output.
- Undo stack overflow: clear oldest entries.

## Performance

- Canvas render: < 16ms (60 FPS).
- Property update: < 5ms.
- Code generation: < 100ms.
- Undo/redo: < 10ms.
