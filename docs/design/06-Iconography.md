# Iconography

## System

Scilab Studio uses a custom icon set based on Lucide icons (MIT licensed). Icons are rendered as SVG inline.

## Sizes

| Size | Dimensions | Use |
|------|-----------|-----|
| xs | 12×12 | Inline indicators |
| sm | 16×16 | Menu items, tree view |
| md | 20×20 | Toolbar buttons, panel tabs |
| lg | 24×24 | Sidebar navigation |
| xl | 32×32 | Welcome screen, empty states |

## Colors

- Icons inherit the text color of their parent.
- Active/selected icons use `--ss-accent`.
- Disabled icons use `--ss-text-secondary` at 50% opacity.

## Rules

- Icons always have text labels in menus and toolbars (no icon-only buttons except in compact toolbars).
- Icons are not decorative. Every icon communicates meaning.
- Custom icons must follow the same stroke style and dimensions.
