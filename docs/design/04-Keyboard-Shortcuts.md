# Keyboard Shortcuts

## Global

| Shortcut | Action |
|----------|--------|
| Ctrl+S / Cmd+S | Save project |
| Ctrl+Z / Cmd+Z | Undo |
| Ctrl+Shift+Z / Cmd+Shift+Z | Redo |
| Ctrl+P / Cmd+P | Command palette |
| Ctrl+, / Cmd+, | Settings |
| Ctrl+J / Cmd+J | Toggle bottom panel |
| Ctrl+B / Cmd+B | Toggle left sidebar |
| Ctrl+Shift+B / Cmd+Shift+B | Toggle right sidebar |
| Ctrl+Shift+D / Cmd+Shift+D | Debug panel |
| F1 | Help / Learning Center |
| Ctrl+= / Cmd+= | Zoom in |
| Ctrl+- / Cmd+- | Zoom out |
| Ctrl+0 / Cmd+0 | Reset zoom |
| Ctrl+N / Cmd+N | New project |
| Ctrl+O / Cmd+O | Open project |
| Ctrl+W / Cmd+W | Close current tab |
| Ctrl+Shift+W / Cmd+Shift+W | Close all tabs |

## Editor

| Shortcut | Action |
|----------|--------|
| Ctrl+F / Cmd+F | Find |
| Ctrl+H / Cmd+H | Find and replace |
| Ctrl+G / Cmd+G | Go to line |
| Tab | Indent |
| Shift+Tab | Outdent |
| Ctrl+D / Cmd+D | Duplicate line |
| Ctrl+/ / Cmd+/ | Toggle comment |
| Ctrl+Shift+K / Cmd+Shift+K | Delete line |
| Alt+Up / Alt+Up | Move line up |
| Alt+Down / Alt+Down | Move line down |
| F5 | Run Scilab script |

## Navigation

| Shortcut | Action |
|----------|--------|

| Ctrl+Tab | Next tab |
| Ctrl+Shift+Tab | Previous tab |
| Ctrl+PageUp / Cmd+PageUp | Previous tab (alt) |
| Ctrl+PageDown / Cmd+PageDown | Next tab (alt) |
